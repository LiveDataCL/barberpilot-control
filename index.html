📋 Instrucciones de configuración
Paso 1 — Abre Google Sheets y crea una hoja llamada Registros
Paso 2 — En la hoja, ve a Extensiones → Apps Script
Paso 3 — Borra el contenido y pega el código del archivo apps_script.gs
Paso 4 — Clic en Implementar → Nueva implementación → Tipo: Aplicación web
Paso 5 — Ejecutar como: Yo · Quién tiene acceso: Cualquier persona
Paso 6 — Copia la URL generada y pégala arriba
Paso 7 — El dashboard de socios lee la misma hoja. Comparte el link del dashboard.
